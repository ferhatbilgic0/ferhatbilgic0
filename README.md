## 🔨 What I've Built

### ✂️ Berber Randevu Sistemi
A full-stack appointment scheduling system designed for barber salons. Built on PHP/CodeIgniter with MySQL. Customers can book online; salon owners manage everything — staff, services, schedules — from a single admin panel. Fully in Turkish, runs locally or on a server.

🔗 [github.com/ferhatbilgic0/berber-randevu-sistemi](https://github.com/ferhatbilgic0/berber-randevu-sistemi)

### 🧍 Postüra — AI-Based Posture Correction System
`January 2025 – October 2025`

A 10-month self-initiated project. Built an AI system in Java and Python that monitors body posture in real time using sensor data and provides feedback to help prevent musculoskeletal issues. Handled everything from hardware integration to software architecture.

### 🚦 Opticity — Smart Urban Traffic Optimization
`2025`

A concept system for real-time urban traffic management — adaptive signal control, route prediction, and smarter city mobility.

### 🌱 AgroSense — AI-Assisted Agriculture System
`2025`
